# Nova Video — مشروع Android Kotlin

## ما تتضمنه هذه النسخة
- واجهة داكنة عربية باستخدام Jetpack Compose.
- مشغل Media3 ExoPlayer للروابط المباشرة المدعومة مثل MP4 وHLS/M3U8.
- قاعدة بيانات SQLite محلية تحفظ عناوين الفيديو وروابطها وأسماء المصادر، وتبقى البيانات بعد إغلاق التطبيق.
- إضافة وحذف الفيديوهات، ومنع تكرار الرابط نفسه.
- بحث محلي حسب عنوان الفيديو والرابط واسم المصدر.
- لا توجد مكتبة إعلانات مضافة من التطبيق.

## حدود مهمة
هذا ليس نسخة رسمية من YouTube ولا يستنسخ شيفرته أو واجهته بالكامل. روابط صفحات YouTube العادية ليست روابط بث مباشرة لتشغيلها في ExoPlayer. لا يقوم التطبيق بإزالة إعلانات خدمات أخرى أو تجاوز تسجيل الدخول أو DRM. استخدم روابط فيديو تملك حق تشغيلها. دعم الفيديو يعتمد على الخادم والصيغة والمصادقة المطلوبة.

## فتح المشروع
1. فك ضغط الأرشيف.
2. افتح مجلد `novavideo` في Android Studio.
3. استخدم JDK 17 وثبّت Android SDK 36 أو عدّل `compileSdk` في `app/build.gradle.kts` إلى نسخة متاحة لديك.
4. نفّذ Gradle Sync، ثم شغّل التطبيق.
5. لإنشاء APK: Build > Build APK(s).
6. المسار المعتاد: `app/build/outputs/apk/debug/app-debug.apk`.

## بناء APK باستخدام الهاتف فقط عبر GitHub Actions
1. أنشئ مستودع GitHub خاصاً.
2. ارفع ملف `NovaVideo-Complete-MobileBuild.zip` إلى جذر المستودع.
3. أنشئ الملف `.github/workflows/build.yml` والصق محتوى `BUILD_ON_GITHUB.yml` المرفق في الأرشيف.
4. افتح Actions، اختر Build Nova Video APK، ثم Run workflow.
5. بعد نجاح البناء افتح العملية ونزّل Artifact باسم `NovaVideo-APK`. فك ضغطه للحصول على `app-debug.apk`.

## إضافة مصادر
من واجهة التطبيق أدخل عنوان الفيديو المباشر واسم المصدر، مثل خادمك الخاص أو CDN أو خدمة بث مرخّصة. يتم حفظ كل مصدر محلياً. هذه النسخة لا تستورد تلقائياً فهرس JSON ولا تجلب نتائج بحث عالمية؛ ذلك يتطلب إضافة API محدد المصدر.
